# Dhisha M — Portfolio

A responsive static portfolio built with HTML, CSS, and JavaScript. No build tools are required.

## Run locally
Open `index.html` in a browser.

## Publish with GitHub Pages
1. Create a GitHub repository named `dhisha-portfolio` (or another name).
2. Upload `index.html` and the `assets` folder to the repository root.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch **main** and folder **/(root)**, then click **Save**.
6. Wait for GitHub Pages to publish the site. The URL will be shown in the Pages settings and will normally look like `https://YOUR-USERNAME.github.io/dhisha-portfolio/`.
